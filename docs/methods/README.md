# Methodological notebooks

This folder contains methodological notebooks for complex or consequential analysis steps in the project.

The notebooks complement, rather than replace, the executable R scripts in `04_code/`. Each notebook reproduces the relevant workflow while documenting methodological decisions, diagnostics, assumptions, exclusions, and interpretation.

Where possible, notebooks use the same base filename as the R script they document. For example:

* `04_code/01_import-clean/09_construct_ess_political_exposure.R`
* `docs/methods/09_construct_ess_political_exposure.qmd`

Not every R script requires a methodological notebook. Companions are added where the analysis involves substantive judgement, non-obvious data transformations, important diagnostics, or decisions that should be transparent and reproducible.
