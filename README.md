# Economic Inequality, Political Discourse, and Social Cohesion in Europe

## Project overview

This repository contains the reproducible computational work for a research project examining whether economic inequality predicts lower social trust and greater perceived social conflict in Europe, and whether these relationships vary according to the intensity and divisiveness of political discourse.

The intended output is a journal article.

## Current status

The project is currently in the conceptual planning and literature-development phase.

## Research question

Does economic inequality predict lower social trust and greater perceived social conflict in Europe, and are these relationships stronger in countries or periods characterised by more divisive political discourse?

## Repository structure

* `R/`: reusable R functions and data-processing scripts
* `data/`: local data directories and data documentation
* `output/`: generated tables, figures, and model outputs
* `manuscript/`: Quarto, R Markdown, or other manuscript files
* `README.md`: project overview and reproducibility information

## Data availability

Raw or restricted data are not stored in this repository. Data-access information and instructions for reproducing the analytical dataset will be documented as the project develops.

## Research documentation

The broader project plan, literature collection, decision log, and research documentation are maintained in the associated Open Science Framework project.

## Reproducibility

Information about software versions, required R packages, and the order in which scripts should be run will be added as the analytical workflow develops.
